Tech Stack and Dev Tools
  • Core development language is GO
  • Quick launch of apps on the EVM-compatible C-Chain
  • dApps built on top of the Camino backend
  • Full EVM compatibility, supporting every Smart-Contract based standard. For instance ERC-20 (Fungible Token), ERC-721 (Non-Fungible Token), ERC-1155 (Fungibility-Agnostic Token) and ERC-2771 (Secure Meta-Transactions).
  • Easy adoption of Ethereum Smart contracts and dApps

Camino Messenger

Camino Messenger is a B2B transactional distribution layer for travel. Built on top of Camino Network, it streamlines peer-to-peer interactions with the help of bots, standardized message types, micropayments, and microservices, enabling personalized offers at scale.
